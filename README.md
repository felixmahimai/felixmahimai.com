# felixmahimai.com

Static Next.js site (App Router, Tailwind), deployed to GitHub Pages.

## Run locally
    npm install
    npm run dev

## Deploy
1. Push to the `main` branch of your GitHub repo.
2. In the repo: Settings > Pages > Source > GitHub Actions.
3. Set the custom domain to felixmahimai.com and tick Enforce HTTPS once available.
